On a building site a survey error does not stay on paper. A column grid set out 50 millimetres wrong is found when the steel does not fit; a slab level carried up wrong is found when the doors do not. Construction surveying is mostly about making sure that never happens, and about being able to show that it did not.

We work from the approved drawings and from control that has been checked on site. Points are set out, then checked independently before anyone builds on them. Levels are carried from a benchmark and closed back onto it. Each step is written down with the coordinates, the instrument and the check, so the site has a record it can hand to the client or the engineer.

When the work is done, an as-built survey measures what was actually built and compares it with the design. That is the record for sign-off and the base for any work that follows.
